# AprilTag 区域表面提取、可靠多视角融合与压力棒遮挡补全

## 目标与产物

对 capture_20261014_202456 的每个时间点，生成标签区域内的单层高度表面，而非物体体积点云。保留原始逐视角深度与置信度。输出分为：

- `surface_observed.ply`：通过可见性、压力棒遮罩及多视角一致性检查的表面。
- `surface_inferred.ply`：遮挡区的模型估计，含补全方法、距离和不确定度；不冒充测量。
- `surface_display.ply`：二者合并，仅用于观察；用颜色区分来源。
- `surface.npz`：规则局部坐标网格的高度、相对参考的形变、来源视角、视角离散程度、掩码、同步质量及不确定度。
- `pairs.npz`：与对应时刻 16×16 ADC 阵列关联；只在空间配准核验通过后生成。

表面分辨率建议先用 2mm 做融合与质检，再按真实物理位置聚合至 7.5mm 单元。网格间距不是精度声明。主标签为法向下沉：`d_t(u,v) = h_rest(u,v) - h_t(u,v)`，单位 mm。光学表面固定空间位置的下沉与随材料运动的单元形变不总相同；若薄膜明显横向滑移，需要另做非刚性对应与拉格朗日标签。

## 0. 先解决范围与坐标的歧义

实际数据的 session/sensor_grid.json 给出标签内角边长 94.44 / 93.31mm；脚本按 16×16、pitch=7.5mm 外推有效区为 120×120mm。三个已三角化标签测得边长 14.62–14.71mm，接近标称 15mm；R1C16 是用平行四边形补出的。仓库 calibration/sensor_grid.json 是另一个较早的网格，不能直接替换本次采集网格。

必须区分：

1. **标签 ROI**：四个实际内角围出的四边形，本次原型采用这一范围，不强制拉成120mm。
2. **传感器有效区**：由实际电极位置、间距、行列方向和标签相对安装偏移决定。不能把94mm区域直接均分16格，再与7.5mm间距的ADC阵列一一配对。

核验办法：在未受压原始图像中重新检测四个 ID 的角点，核对标记字典与朝向；逐角至少两台相机三角化并做留一相机重投影检查；对缺失角选择其他无遮挡时间点独立测量。用打印尺寸和实测标签间距核对尺度。在四视角图像上叠加 ROI、16×16 单元与 R1C1 标识；用若干已知单元的独立定位按压核验行列、翻转和偏移。标签本身随薄膜运动时，用基底固定标记估计刚体漂移，不能用受压角点重新拟合平面而消除真实形变。

## 1. 坐标和 ROI

从无载多帧标签位置鲁棒估计参考平面，确定固定局部坐标 `(u,v,w)`：u沿列、v沿行、w朝上。原始世界点先由米转mm，再变换。ROI采用局部平面内的凸四边形与可选向内2–3mm安全边界，避免标签厚度和物体侧面进入；不要只使用世界xy矩形。

记录标签角点误差及缺失标记。检测不到时短时沿用已经确认的固定ROI，并标记状态；不能静默无限外推。若整个试样移动，分离刚体运动与局部形变，并保留两种量。

## 2. 压力棒分离：优先在各相机深度图中做

优先使用每帧 depths.npz 中的逐视角深度、置信度、处理后的内参和外参，而非已经体素合并的 fused.ply。按当前处理尺寸重建去畸变RGB，确保分割遮罩与深度严格同像素。

1. 在代表帧人工勾勒黑色压力棒/压头，建立二值遮罩。可用分割模型与时间传播辅助，但要人工检查接触、反光及最深按压帧。
2. 压力棒的黑色只作为辅助特征，不能单独以RGB阈值删除所有黑点。阴影、标签黑块和表面纹理可能同色。
3. 分割边缘适量膨胀，膨胀量按实际投影对应的毫米范围选择，验证1/2/3像素敏感性；保留“压头主体”和“接触边界不确定带”两个掩码。
4. 结合已知竖直运动轴、棒的长方体/圆柱尺寸和跨帧位姿，拟合三维刚体压头。将几何模型反投影到各相机，检查分割一致性，并剔除高度落在参考面附近但实际属于下降压头的点。
5. 使用参考表面附近的宽高度带作为候选范围，例如下方35mm、上方8mm；具体范围根据最大行程和噪声实测调整。不能简单永久保留 `w<参考+2mm`：接触后的压头侧面可能低于未压表面；表面局部也可能上拱。
6. 深度边缘、飞点和高法向噪声另行剔除。失去纹理/被遮挡的区域不因DA3生成了连续深度就认定可见。

## 3. 多视角可靠融合

每个2mm局部格中，每台相机先独立计算鲁棒高度（中位数或局部曲面交点）、有效像素数、置信度、入射角和散布。侧面/竖直边不应参与上表面统计，但不能用过严法向阈值删掉凹陷陡壁。

先从无载参考帧估计每个视角的高度偏差与噪声，再融合相对形变，避免把RGB/D455的固定偏移当成动态形变。这个操作是相对标签校正，不证明绝对深度正确；原始高度和偏差图必须保留。不要根据每一受压帧拟合独立偏移，否则会吸收真实变形。

格内高度有两层时做一维聚类，依据表面连续性、语义遮罩和相机可见性选择表面簇；存在歧义时不输出高置信测量。每个视角最多一票，避免高像素密度相机支配融合。至少两路相机支持可作为初始规则；四路DA3同模型推理相互相关，两个视角同意不是两个独立真值。

使用置信度、入射角和无载噪声加权的鲁棒估计（Huber/加权中位数），输出支持视角集合与MAD。原型的3mm簇门限只是初始实验参数，应做1/2/3/5mm扫描。只在视角已确认看到同一表面时融合；空洞或双层不要直接均值。

D455时差绝对值>40ms的18帧，在标签融合时禁用该路，保留RGB结果。其余帧也应按运动速度评估时间误差；40ms不是所有压入速度下都合格。用力计行程变化检查压力棒高度轨迹，但不能用目标触觉ADC来调几何标签，否则产生标签泄漏。

## 4. 遮挡补全：按可识别程度分级

### A. 小尺度、四周可见的孔洞

先使用局部薄板样条、双调和最小曲率或带正则的局部曲面拟合作候选；拉普拉斯插值作为基线。数据项只拟合实测点，正则抑制高频振荡。根据距离、邻域曲率、边界支持角度、视角离散和交叉验证误差决定是否接受。输出不确定度和单独inferred掩码。

必须测试局部极值是否被抹平。平滑系数不能按“看起来好看”选，应按按压状态分层的留出误差选择。只有单侧边界、连接ROI边缘或超出支持范围的孔洞，不当成小孔强行封闭。

### B. 压力棒下方的接触区

纯周围点云不能唯一确定隐藏凹陷的深度。需要几何约束：测量压头形状、尺寸、运动轴及平面朝向；从可见棒侧面恢复位姿；以可靠接触时刻和行程估计接触面高度，检查机架顺应性/试样整体移动。平头、充分接触区域可以用压头底面提供高度约束，圆头用已知刚体表面；不能把投影轮廓的整个范围都假定为实际接触。

构建约束曲面优化：

`E = E_visible + λ_s E_bending + λ_t E_temporal + λ_c E_contact`

可见区保留测量误差权重；接触区拟合已标定的压头表面；非接触区遵守不穿透压头的约束。接触边界通过几何、图像和加载状态共同估计，作为不确定变量。λ_t仅在同一按压阶段使用，不跨加载/卸载快速变化强行平滑。上下文不足的中心保留NaN；可以另给低置信可视化估计。

### C. 大面积/单侧不可见区域

若要完整训练标签，需追加实验：透明压头/不同观察角、可见侧壁的更窄压头、已知形状的标定样件、或经独立材料试验验证的有限元模型。FEM需要材料和边界参数及滞回验证，不应仅凭海绵外观设定。估计结果和实测结果分别训练/加权。

## 5. 当前已运行的测试

脚本：`scripts/surface_roi_experiment.py`。输入各相机独立PLY及本次session的sensor_grid.json；2mm局部网格，每格每视角至少3个点，视角最多一票，至少2票，3mm初始一致性门限。无载参考使用0/10/20/30/40帧；真实发布前仍需检查这些参考是否完全无载且无遮挡。基线剔除深色中性点及明显高处点，不能代替压力棒语义分割。

先对每路计算相对自身无载参考的下沉，再取一致视角中位数；绝对表面使用融合参考高度重建。每格保存observed、inferred、支持视角数、MAD。补全基线为固定测量值的拉普拉斯解，距测量点超过12mm不输出。这个距离规则不能代替闭合边界和接触模型检查。所有补全均为低置信实验估计。

### 合成真值测试

通过：已知倾斜平面圆孔重建误差<1e-8mm；不修改已观测值；无观测数据时拒绝补全；超过距离上限保留NaN；多视角孤立异常值被拒绝。

针对幅值12mm、标准差8mm的高斯凹陷，遮住中心：

| 遮挡半径 | 遮挡区MAE | 中心压深低估 |
|---|---:|---:|
| 4mm | 0.91mm | 1.60mm |
| 8mm | 2.45mm | 4.96mm |
| 12mm | 3.54mm | 8.25mm |

这是对“周围平滑足以恢复隐藏接触中心”的反例，应据此引入压头约束，而不是将插值当真值。

### 真实数据人工遮挡测试

对每个代表帧的已观测表面，以固定随机种子73随机取最多30个中心，人工删除半径4/8/12mm圆区；只比较原先有值、补全成功的格。由于真实空洞本来就存在，不保证每次圆区完整可观测；各帧实际有效试验数22–29。完整试验明细在report.json。

| 遮挡半径 | 5帧各自“试验MAE的中位数”范围 |
|---|---:|
| 4mm | 0.23–0.39mm |
| 8mm | 0.32–0.51mm |
| 12mm | 0.39–0.66mm |

这仅说明对已经可见、较平滑、且被基线融合的表面的插值能力。第435帧12mm组最差单次MAE达2.28mm；不能把小的中位数外推至真正被压力棒遮住的最大凹陷。该测试也没有独立验证DA3本身的准确度。

## 6. 正式实现的测试矩阵与验收

以下阈值是建议目标，尚未达成验证；应按数据集所需最小可区分形变量修改。

| 层次 | 测试 | 指标与建议验收 |
|---|---|---|
| 标签定位 | 四视角叠加、留一视角三角化、独立尺量、缺角恢复与真实角对比 | 检查内角误差/尺度/行列；推荐实测单元位置误差<半个单元，理想<1mm |
| 坐标 | 已知刚体旋转平移、米/mm、法向正负、网格行列 | 数值单测通过，已知向下位移得到正下沉 |
| ROI | 边界内外测试、倾斜平面、侧壁、多边形边缘 | 所有输出点在ROI内；侧壁不进入高度层 |
| 棒分割 | 至少30帧分层人工标注：无载/加载/保持/卸载、浅/深压 | mask IoU、接触边缘漏棒率、误删表面率；单独审查接触边缘 |
| 静态噪声 | 真实未加载段，不同视角与D455分别测 | 每格时间std、P95漂移、参考污染；不能用平滑后结果报告原始精度 |
| 融合 | 留一视角预测其可见高度；RGB4与D455分别评估 | MAE/P95、偏差、覆盖；强相关DA3多视角不视作独立真值 |
| 遮挡补全 | 合成平面/高斯/平头接触/陡边，4/8/12/20mm孔洞 | MAE、P95、最大凹陷误差、边界梯度；按孔大小和曲率分层 |
| 真实留出 | 不只随机平坦区，强制覆盖可见凹陷极值/陡壁/ROI边缘 | 独立调参集与评估集，报告最差值和拒绝率；建议高置信估计MAE≤1mm、P95≤2mm再纳入标签 |
| 接触约束 | 已知压头姿态/行程的标定物体 | 中心高度与压入行程一致性、非穿透、接触区覆盖；检测滑移/机架误差 |
| 时序 | 故意错位±1/±2帧，快速加载与保持分别检查 | 形变/行程滞后与速率误差；禁用不合格D455帧 |
| 不确定度 | 独立留出误差对预测区间的覆盖校准 | 例如90%区间覆盖接近90%；不得只按距离造“置信度” |
| 数据集 | 索引唯一、ADC行列、NaN掩码、来源分离、单位 | 推断值不可写入observed；按完整按压/采集划分训练验证，避免相邻帧泄漏 |

## 7. 分阶段交付

1. 核验标签ROI与真实电极区关系，输出四视角叠加图和坐标/尺寸检查。
2. 建立压力棒语义+几何遮罩，在5个代表帧和30帧标注集验证。
3. 实现原始深度的多视角可靠表面融合，输出观测覆盖、拒绝图和独立验证结果。
4. 实现小孔曲面补全与压头接触约束两套方法；比较纯插值、约束补全及不补全三种基线。
5. 在网页增加实测表面/估计表面/形变热图/可靠性图、压头轮廓和16×16叠加；用户检查后批量生成871帧标签。
6. 输出数据集与数据卡：标签来源、标定版本、参考帧、缺失原因、补全算法、不确定度、同步质量与划分清单。

## 复现当前实验

在reconstruction目录运行：

```bash
.venv-da3/bin/python scripts/surface_roi_experiment.py \
  --run outputs/rgbd_20261014 \
  --grid data/drive_test/capture_20261014_202456/sensor_grid.json \
  --output outputs/surface_roi_experiment
```

此命令无需重跑DA3，也不改写原始重建。输出5组观测/推断PLY与NPZ、surface_experiment.png和report.json。完整生产分离和接触约束优化尚未实现；当前结果用于方案选择。
